# Instalndo nvm y pnpm en fish

## Instalción de nvm con fisher

```bash
fisher install jorgebucaran/nvm.fish
nvm --version
```

## Instalación de pnpm

```bash
npx get-pnpm
```

## Recargamos fish

```bash
source ~/.config/fish/config.fish
pnpm --version
```

## Configuración de pnpm

```bash
pnpm setup
```
