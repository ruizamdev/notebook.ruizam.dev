# 🌐 Chuletón de comandos para troubleshooting de redes

Referencia rápida de comandos para **diagnóstico, inspección y configuración de redes** en Windows y Linux.

---

# 1. Información de interfaces

## Windows

### `ipconfig`

Información básica de interfaces.

```powershell
ipconfig
```

Información completa:

```powershell
ipconfig /all
```

Muestra, entre otros:

- IPv4 / IPv6
- Máscara de subred
- Gateway
- Servidores DNS
- DHCP habilitado
- Servidor DHCP
- Dirección MAC
- Lease DHCP

---

### PowerShell

```powershell
Get-NetAdapter
```

Interfaces disponibles y estado.

```powershell
Get-NetIPConfiguration
```

Configuración IP resumida.

```powershell
Get-NetIPConfiguration -Detailed
```

Información detallada.

```powershell
Get-NetIPAddress
```

Direcciones IP configuradas.

```powershell
Get-NetIPInterface
```

Información lógica de las interfaces.

---

# 5. Configuración IP manual

## Windows

### PowerShell

```powershell
New-NetIPAddress \
  -InterfaceAlias "Ethernet" \
  -IPAddress 192.168.1.100 \
  -PrefixLength 24 \
  -DefaultGateway 192.168.1.1
```

DNS:

```powershell
Set-DnsClientServerAddress \
  -InterfaceAlias "Ethernet" \
  -ServerAddresses ("1.1.1.1","8.8.8.8")
```

Volver DNS a automático:

```powershell
Set-DnsClientServerAddress \
  -InterfaceAlias "Ethernet" \
  -ResetServerAddresses
```

---

### `netsh`

```cmd
netsh interface ipv4 show interfaces
```

IP estática:

```cmd
netsh interface ipv4 set address name="Ethernet" static 192.168.1.100 255.255.255.0 192.168.1.1
```

DHCP:

```cmd
netsh interface ipv4 set address name="Ethernet" source=dhcp
```

DNS:

```cmd
netsh interface ipv4 set dns name="Ethernet" static 1.1.1.1
```

---

## Linux

### IP temporal

```bash
sudo ip addr add 192.168.1.100/24 dev eth0
```

Eliminar:

```bash
sudo ip addr del 192.168.1.100/24 dev eth0
```

Levantar interfaz:

```bash
sudo ip link set eth0 up
```

Bajar:

```bash
sudo ip link set eth0 down
```

Gateway temporal:

```bash
sudo ip route add default via 192.168.1.1
```

---

### NetworkManager

IP estática:

```bash
nmcli connection modify "CONEXION" \
ipv4.method manual \
ipv4.addresses 192.168.1.100/24 \
ipv4.gateway 192.168.1.1 \
ipv4.dns "1.1.1.1 8.8.8.8"
```

Aplicar:

```bash
nmcli connection up "CONEXION"
```

Volver a DHCP:

```bash
nmcli connection modify "CONEXION" ipv4.method auto
```

# 6. Tabla de enrutamiento

## Windows

```powershell
route print
```

PowerShell:

```powershell
Get-NetRoute
```

Solo IPv4:

```powershell
Get-NetRoute -AddressFamily IPv4
```

Ruta por defecto:

```powershell
Get-NetRoute -DestinationPrefix "0.0.0.0/0"
```

Agregar ruta:

```cmd
route add 10.10.0.0 mask 255.255.0.0 192.168.1.1
```

Ruta persistente:

```cmd
route -p add 10.10.0.0 mask 255.255.0.0 192.168.1.1
```

Eliminar:

```cmd
route delete 10.10.0.0
```

---

## Linux

```bash
ip route
```

Versión corta:

```bash
ip r
```

Ruta por defecto:

```bash
ip route show default
```

Consultar qué ruta usaría hacia una IP:

```bash
ip route get 8.8.8.8
```

Agregar ruta:

```bash
sudo ip route add 10.10.0.0/16 via 192.168.1.1
```

Eliminar:

```bash
sudo ip route del 10.10.0.0/16
```

Agregar default gateway:

```bash
sudo ip route add default via 192.168.1.1
```

# 10. DNS

## Windows

```cmd
nslookup google.com
```

Consultar servidor específico:

```cmd
nslookup google.com 1.1.1.1
```

PowerShell:

```powershell
Resolve-DnsName google.com
```

Tipo específico:

```powershell
Resolve-DnsName google.com -Type A
```

```powershell
Resolve-DnsName google.com -Type MX
```

```powershell
Resolve-DnsName google.com -Type TXT
```

Limpiar caché:

```cmd
ipconfig /flushdns
```

Ver caché:

```cmd
ipconfig /displaydns
```

---

## Linux

### `dig`

```bash
dig google.com
```

Solo resultado:

```bash
dig +short google.com
```

Servidor específico:

```bash
dig @1.1.1.1 google.com
```

Registros:

```bash
dig google.com A
dig google.com AAAA
dig google.com MX
dig google.com TXT
dig google.com NS
```

Resolución inversa:

```bash
dig -x 8.8.8.8
```

Traza DNS:

```bash
dig +trace google.com
```

---

### `resolvectl`

```bash
resolvectl status
```

Consulta:

```bash
resolvectl query google.com
```

Vaciar caché:

```bash
sudo resolvectl flush-caches
```
