# Manejo básico

La gestión de repositorios y paquetes en Fedora se realiza principalmente a través de la herramienta `dnf`, que es el gestor de paquetes predeterminado en esta distribución. A continuación, se describen los comandos básicos para gestionar repositorios.

## Listar repositorios

Para listar los repositorios configurados en el sistema, puedes usar el siguiente comando:

```bash
dnf repolist
```

Como podemos observar mas adelante en la salida, esto nos muestra ID y nombre del repositorio existente en nuestro sistema.

## Habilitar o deshabilitar un repositorio

Fedora utiliza `dnf config-manager`. Si no existe en el sistema, lo podemos instalar así:

```bash
sudo dnf install dnf-plugins-core
```

### Habilitar repo

```bash
sudo dnf config-manager setopt <id-repo>.enabled=1
# Ejemplo:
sudo dnf config-manager setopt fedora.enabled=1
```

### Deshabilitar repo

```bash
sudo dnf config-manager setopt <id-repo>.enabled=0
# Ejemplo:
sudo dnf config-manager setopt fedora.enabled=0
```

Nota: Obviamente el repo `fedora` es el repo oficial del sistema, por lo que no es recomendable deshabilitarlo.

## Actualizar caché/metadata

Después de habilitar o deshabilitar un repositorio, es recomendable actualizar la caché para que los cambios se reflejen correctamente. Esto se puede hacer con el siguiente comando:

```bash
sudo dnf makecache
```

## Ver archivos `.repo`

Los repos viven normalemnte en el directorio `/etc/yum.repos.d/` con la extensión `.repo`, simplemente listamos el contenido de éste para ver los archivos:

```bash
ls /etc/yum.repos.d/
```

Si deseamos ver el contenido basta con abrirlo con cualquier editor de texto o para ver rápido el contenido con `cat`:

```bash
cat /etc/yum.repos.d/fedora.repo
```
