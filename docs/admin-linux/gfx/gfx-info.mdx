# Información de Gráficos

Para obtener información de drivers gráficos y que es lo que esta activo tenemos varias formas de verlo:

---

**Ver GPUs detectadas:**

```bash
lspci | grep -E "VGA|3D|Display"
```

Salida:

```txt
01:00.0 VGA compatible controller: NVIDIA Corporation TU117BM [GeForce GTX 1650 Mobile Refresh] (rev a1)
05:00.0 VGA compatible controller: Advanced Micro Devices, Inc. [AMD/ATI] Cezanne [Radeon Vega Series / Radeon Vega Mobile Series] (rev c6)
```

---

**Ver renderers:**

```bash
glxinfo | grep "OpenGL renderer"
```

si `glxinfo` no aparece como comando, instalalo:

```bash
sudo dnf install mesa-demos
```

Salida:

```json
OpenGL renderer string: AMD Radeon Graphics (radeonsi, renoir, ACO, DRM 3.64, 6.19.14-300.fc44.x86_64)
```

---

vulkaninfo --summary
